# Dispatch Queue Execution

1. Find DQ item.
2. Verify status and dependencies.
3. Read Required Documents.
4. Update status to In Progress.
5. Execute work.
6. Record evidence.
7. Update status to Complete.
8. Update Completion Summary counts.

Do not deviate from architecture without recording a decision.

Create DQ after implementation plan contains executable waves.
Update completion summary after every status change.

Execute **one** DQ item at a time unless the developer explicitly batches items.
