# Web (Angular) — Quick Reference

| Area | Location / rule |
|------|-----------------|
| Features | `src/app/features/{name}/` |
| Shared UI | `src/app/shared/` |
| Auth / interceptors | `src/app/core/` |
| State default | Signals + services |
| Forms | Reactive forms |
| API | `/api/app/...` via HttpClient / OpenAPI client |
| Tests | Colocated `*.spec.ts` |

Full: `critical-rules-web.md`, `patterns/angular-conventions.md`.
