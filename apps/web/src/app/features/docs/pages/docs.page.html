API references for integrating with Documate

Partners subscribe via Business → Integrations & events (queues inherit by default).

  • File received — after file + blob committed (async / email)
  • Document ready / Document failed / Document cancelled — document terminals (rejected maps to failed)
  • File completed — only when all documents on the file are Ready

Headers: X-Documate-Event, X-Documate-Delivery (event id), X-Documate-Signature (HMAC). Sync extract (api_sync) suppresses all public actions.

Settings APIs: /api/app/business/public-actions, /api/app/queues/{id}/public-actions.

FrontendSupport endpoints used by this app:

  • /api/app/me — account context
  • /api/app/queues/…/files — upload, list, search, summary
  • /api/app/agents — agent CRUD
  • /api/app/queues — channels, intake, routes
  • /api/app/api-keys — partner keys
